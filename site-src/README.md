# Исходники страницы

`index.html` в корне репозитория собирается из этих файлов одной командой `node build.js`:

- `market-desk.html`: основа страницы (разметка, стили, утренний отчёт, уровни и цели, вольт);
- `src/live.js`: живые данные Hyperliquid, график, рынки, ETF, ФРС;
- `src/insight.js`: цикл и оценка, шансы касания уровней, настроение и ликвидность, токены;
- `src/nav.js`: закреплённое меню, ссылки на разделы, сворачивание;
- `src/extra.css`: стили всего, что добавлено поверх основы;
- `build.js`: вставляет новые разделы в основу и склеивает всё в один файл;
- `tools/seed.py`: собирает `history.json` из дневного ряда, скачанного с графика реализованной цены Bitbo.

Сборщик ждёт рядом папки `web/` (результат), `webdata/data.json` и копии `watchlist.json`, `fed.json`,
`fed-calendar.json`, `levels.json`, `history.json` в `src/`: это файлы из корня репозитория.
