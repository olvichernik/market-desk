# Market Desk

Статический сайт: `index.html`, данные утренних отчётов в `data.json`, библиотека графиков в `vendor/`.

- Цена, свечи, фандинг и позиции вольта запрашиваются из браузера у публичного API Hyperliquid.
- Графики рынков и календарь показывают виджеты TradingView.
- `data.json` дополняется раз в день: массив `digests` (по одной записи на дату).

Не инвестиционная рекомендация.
